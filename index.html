    Ссылка для вашей половинки:

    Отправьте эту ссылку в Telegram — таблица на втором телефоне подключится сама в 1 клик:

    Инструкция по настройке (один раз за 2 минуты):

    1. Откройте sheets.new и создайте пустую Google Таблицу (назовите «Свадьба 2026»).

    2. В верхнем меню таблицы выберите «Расширения» → «Apps Script», удалите весь текст и вставьте этот мини-код:

    function doGet(e){var s=SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();var d=s.getRange('A1').getValue();return ContentService.createTextOutput(d||'{}').setMimeType(ContentService.MimeType.JSON);}
function doPost(e){var s=SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();if(e&&e.postData&&e.postData.contents){s.getRange('A1').setValue(e.postData.contents);}return ContentService.createTextOutput('{"status":"ok"}').setMimeType(ContentService.MimeType.JSON);}

    3. Справа вверху нажмите синюю кнопку «Начать развертывание» → «Новое развертывание»:

    • Тип: выберите «Веб-приложение» (шестеренка слева).
    • У кого есть доступ: выберите «Все» (Anyone).
    • Нажмите «Развернуть» и скопируйте полученную ссылку на веб-приложение в поле выше.
